# Ухо торговца — ABI

Помощник для полевого торговца в Arena Breakout: Infinite: слушает звук игры и по звуку ящика показывает, какие предметы могут быть внутри и есть ли среди них красные.

Работает целиком в браузере (Chrome или Edge на ПК), ничего никуда не отправляет. Звуки ящиков в репозитории не хранятся — файл со звуками загружается на странице один раз.
